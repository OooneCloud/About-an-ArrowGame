# 一箭又一箭

使用 Python + pygame 开发的“一箭又一箭”风格点击式箭头解谜小游戏（软件工程第二次个人作业）。

## 游戏简介

棋盘中散布着朝上（↑）、下（↓）、左（←）、右（→）四个方向的箭头。玩家点击某个箭头后，程序会检查该箭头前进方向上直到棋盘边界之间是否还有其他箭头：

- **前方无阻挡**：箭头飞出棋盘并被消除；
- **前方有阻挡**：箭头不能消除，会晃动并提示碰撞，同时消耗 1 点生命；
- **清空本关全部箭头**：通关，进入下一关；
- **生命值耗尽**：本关失败，可重新开始。

游戏包含 **8 个固定关卡**（第 1 关手工设计的新手关，其余为 v3.0.0 生成器生成并经过可解性校验），箭头数量从 9 个递增到 62 个，棋盘从 5×5 扩大到 10×10，后几关生命值降为 2 点，难度逐步提升。所有关卡均通过方向均衡、象限分散与方向-位置分散校验：每个关卡不同方向箭头数量极差 ≤ 5，箭头分散在棋盘各处，不会出现“一整行同一方向”“大片区域只有两种箭头”或“左箭头全在左侧、下箭头全在下部”这类聚在自己指向方向的规律布局。此外还有 **挑战关卡**（10×10 随机高密度棋盘，生命 3 点、撤销/提示各限 1 次），每次进入随机生成。

**每关限时**：HUD 显示剩余秒数（≤10 秒变红），超时未通关则本关失败；**通关后按“用时 + 生命消耗 + 撤销次数 + 提示次数”评定 1~5 颗星**，全部通关界面显示总星数（满分 40 星）。

**辅助功能**（按钮位于棋盘下方）：
- **撤销上一步**：每关最多 3 次；可撤销一次消除或失误（生命 +1）；因生命耗尽失败时也可撤销一步挽回，超时失败不可撤销；**撤销 1 次扣 1 分、≥2 次扣 2 分**；
- **提示**：每关最多 3 次；高亮一个当前可直接消除的箭头（金色闪烁边框）；**用过提示扣 1 分**；
- **AI 求解**：用贪心求解器自动算出通关顺序并逐部执行，自动通关当前关卡（求解期间暂停倒计时）；**使用 AI 求解的本关直接评定 1 星**。

## 关卡难度表

| 关卡 | 名称 | 棋盘 | 箭头数量 | 生命值 | 限时（秒） |
| --- | --- | --- | --- | --- | --- |
| 第 1 关 | 初出茅庐 | 5×5 | 9 | 3 | 40 |
| 第 2 关 | 小试锋芒 | 6×6 | 16 | 3 | 55 |
| 第 3 关 | 渐入佳境 | 6×6 | 18 | 3 | 60 |
| 第 4 关 | 箭指四方 | 7×7 | 22 | 2 | 75 |
| 第 5 关 | 乱箭齐飞 | 8×8 | 42 | 2 | 90 |
| 第 6 关 | 疾风骤雨 | 9×9 | 48 | 2 | 100 |
| 第 7 关 | 十面埋伏 | 10×10 | 55 | 2 | 115 |
| 第 8 关 | 百步穿杨 | 10×10 | 62 | 2 | 130 |
| 挑战关卡 | 随机生成 | 10×10 | 高密度（尽可能铺满） | 3 | 180 |

固定关卡采用“关卡选择”模式：通关上一关解锁下一关；挑战关卡随机生成（每次不同），撤销/提示各限 1 次。所有固定关卡与挑战关卡均通过方向均衡（各方向箭头数极差 ≤ 5）、象限分散与方向-位置分散（各方向箭头平均位置贴近棋盘中心）校验。

## 评分规则

通关后按“用时 + 生命消耗 + 撤销次数 + 提示次数”评定 **1~5 颗星**（满分 40 星，全部通关界面显示总星数）：

| 条件 | 星级 |
| --- | --- |
| 快速（用时 ≤ 限时的 50%）、无生命消耗、未用撤销和提示 | ★★★★★ |
| 用时 ≤ 限时的 75%、生命消耗 ≤ 1 点、撤销 ≤ 1 次、未用提示 | ★★★★ |
| 其余情况：按“用时分 + 生命分 + 撤销分 + 提示分”扣减，通关保底 1 星 | ★ ~ ★★★ |
| 使用过 AI 求解（无论其他表现） | ★ |

判定顺序：星级 = `max(1, 5 - (时间分 + 生命分 + 撤销分 + 提示分))`，其中时间分 = 用时占比 ≤50%→0、≤75%→1、否则→2；生命分 = 消耗生命 0 点→0、1 点→1、≥2 点→2；撤销分 = 撤销 0 次→0、1 次→1、≥2 次→2；提示分 = 提示 0 次→0、≥1 次→1。使用 AI 求解直接判定 1 星。限时耗尽则本关失败（超时失败与生命耗尽同样进入失败界面）。

## 安装和运行方法

```bash
# 1. 安装依赖（只需 pygame）
pip install -r requirements.txt

# 2. 运行游戏
python main.py
```

运行测试（可选）：

```bash
python -m unittest discover -s tests -v
```

## 游戏操作说明

- **开始界面**：点击“关卡选择”进入选关界面（通关上一关解锁下一关，已通关关卡显示获得的星数，可重刷）；点击“挑战关卡”直接进入随机生成的 10×10 高密度关卡（撤销/提示各限 1 次）；
- **游戏界面**：鼠标左键点击棋盘中的箭头；
  - 顶部显示：当前关卡、剩余生命（红点，不显示数量）、剩余时间（≤10 秒变红）和“重新开始”按钮；棋盘下方是“撤销 / 提示 / AI求解”功能按钮；
  - 箭头成功飞出时会有滑出动画，并播放程序生成的“嗖”声效；
  - 点击被阻挡的箭头时，箭头晃动、出现红色提示文字，生命值减 1；
  - **撤销**：恢复上一步（消除的箭头回到原位，或生命 +1），每关限 3 次，按钮显示剩余次数，用尽后置灰；
  - **提示**：金色边框高亮一个可消除的箭头，每关限 3 次，按钮显示剩余次数，用尽后置灰；
  - **AI求解**：自动按求解顺序通关当前关卡（本关评分直接 1 星）；求解期间撤销/提示/AI求解按钮置灰禁用（棋盘也锁定），仅“重新开始”可随时中断；
- **通关界面**：等最后一个箭头完全飞出棋盘后弹出，显示用时、生命消耗与评定的 1~5 颗星；非最后一关点击“下一关”继续，**最后一关显示“查看总星数”**，点击后进入全部通关界面；
- **失败界面**：生命值耗尽或限时耗尽都会失败，点击“重新开始”恢复本关初始状态；
- **全部通关后**：显示总星数（满分 40 星），点击“返回主菜单”回到开始界面。

## 项目结构

```
arrow-game/
├── main.py               # 游戏入口：pygame 界面、动画、主循环
├── game.py               # 核心逻辑：棋盘、路径检测、点击处理、关卡状态机、可解性求解器、关卡生成器
├── levels.py             # 关卡数据（8 个已校验可通关的固定关卡 + 挑战关卡配置，难度递增）
├── requirements.txt      # 依赖
├── README.md
├── tests/
│   └── test_game.py      # 自动化测试（覆盖作业要求 T01-T06、评分 T07-T12、撤销/提示/AI求解等，共 53 个用例）
├── tools/
│   ├── generate_level.py        # 随机生成可通关关卡（附加功能）
│   ├── make_screenshots.py      # 无窗口生成各界面截图（早期版本）
│   ├── make_screenshots_v22.py  # v2.2.1 界面截图生成脚本
│   ├── make_demo_gif.py         # 自动演示并录制 GIF（早期版本）
│   ├── make_extra_gifs.py       # 失败/求解演示 GIF（早期版本）
│   └── make_gifs_v22.py         # v2.2.1 通关/失败/AI求解 演示 GIF 生成脚本
└── screenshots/          # 截图与演示 GIF
```
